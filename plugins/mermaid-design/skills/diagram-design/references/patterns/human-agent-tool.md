# Human Agent Tool

## Use when

Explain delegated work and retained human authority.

## Semantic model

Human requests; agent proposes/calls tool; tool returns; agent reports.

## Visual grammar

Prefer sequence; resolve renderer capability before reading syntax.

## Preserve / avoid

Place required approval before the side effect. Distinguish suggestion from execution.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
