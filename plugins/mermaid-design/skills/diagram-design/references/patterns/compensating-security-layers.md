# Compensating Security Layers

## Use when

Explain independent mitigations and remaining exposure.

## Semantic model

Threat → preventive control → detective control → response.

## Visual grammar

Prefer flowchart; resolve renderer capability before reading syntax.

## Preserve / avoid

Layers mitigate different failure modes; do not imply risk reaches zero or that controls are interchangeable.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
