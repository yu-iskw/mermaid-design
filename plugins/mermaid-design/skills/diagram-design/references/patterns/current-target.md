# Current Target

## Use when

Explain a migration rather than just two disconnected snapshots.

## Semantic model

Current → transition → target, with the transition dependency explicit.

## Visual grammar

Prefer flowchart; resolve renderer capability before reading syntax.

## Preserve / avoid

Do not imply simultaneous operation or zero downtime unless supplied.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
