# Paired Policy Traces

## Use when

Compare allowed and denied behavior under one policy.

## Semantic model

Shared request and decision, then allowed and denied traces.

## Visual grammar

Prefer sequence; resolve renderer capability before reading syntax.

## Preserve / avoid

Keep actor and operation constant so the policy difference is visible.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
