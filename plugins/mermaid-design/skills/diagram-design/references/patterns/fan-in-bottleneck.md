# Fan In Bottleneck

## Use when

Explain contention at a shared constrained resource.

## Semantic model

Several producers → queue → constrained worker.

## Visual grammar

Prefer flowchart; resolve renderer capability before reading syntax.

## Preserve / avoid

Separate queue capacity from processing rate; do not invent throughput.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
