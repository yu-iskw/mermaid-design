# Producer Broker Consumer

## Use when

Explain asynchronous decoupling.

## Semantic model

Producer publishes to broker; consumer receives and acknowledges.

## Visual grammar

Prefer sequence; resolve renderer capability before reading syntax.

## Preserve / avoid

Delivery, retries and ordering are separate guarantees. Do not invent exactly-once delivery.

## Removal test

Remove any element that does not explain the primary relationship. Split a second independent question into a separate figure.
